# Low IPTV — Releases

Repositório público de distribuição dos APKs do **Low IPTV**
(app Flutter para celular, Android TV e Google TV).

Os APKs são gerados automaticamente pelo pipeline do repositório privado
[`low-iptv`](https://github.com/junin275/low-iptv) e publicados aqui como
Releases. Instale a versão mais recente pela tela **Ajustes → Atualizações**
do app (botão *Instalar agora*).

> Use apenas fontes IPTV às quais você tem direito.
